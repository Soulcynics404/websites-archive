## 📁 Structure

```
websites-archive/
├── galicia-croydon/      ← one folder per site (index.html, css/, js/, …)
├── stonehenge-cafe/
├── …
└── website-factory/      ← the generator that built the sites
```

Each folder was merged from its original repo with full git history (`git subtree`), so `git log -- <folder>` still shows every change.

## ☁️ Deploying

Sites are static HTML/CSS/JS hosted on **Vercel** (team `soulcynics-team`).

- **Git-connected sites** (including all 10 live ones) redeploy automatically when their own folder changes on `main`; edits to other folders are skipped.
- **Other sites** are deployed from their folder with the Vercel CLI:

```bash
cd <folder> && vercel deploy --prod
```
